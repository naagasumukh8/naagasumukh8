## 🎯 The Mission

> *"I don't build apps. I build systems that fix things that are broken."*

I'm **Sumukh** — a self-taught full-stack engineer from **Bengaluru, India 🇮🇳**, on a single-minded mission:

**Revolutionise how India's 70,000+ hospitals handle patients — starting with the ones who can't even type a Google search.**

My current project, **MediConnect**, uses AI voice calls (in 12 Indian languages) to let elderly patients book doctors, manage prescriptions, and navigate an entire healthcare system — without ever touching a keyboard, signing up, or knowing what email is.

That's not a feature. That's a philosophy.

## 🔥 What I'm Building Right Now

<div align="center">

### 🏥 MediConnect — AI-Powered Healthcare OS

[![MediConnect](https://img.shields.io/badge/MediConnect-Live_Demo-00D4AA?style=for-the-badge&logo=vercel&logoColor=white)](https://mediconnect.care)
[![GitHub](https://img.shields.io/badge/View_Source-181717?style=for-the-badge&logo=github&logoColor=white)](https://github.com/naagasumukh8/mediconnect-care)

</div>

```
What it does — in plain words:

  🗣️  Elderly patient calls a number
  🌐  AI asks: "ನಿಮ್ಮ ಭಾಷೆ ಯಾವುದು?" (Which language?)
  🤖  Human-like AI agent takes over — books doctor, manages history
  📱  Zero login. Zero email. Zero confusion.
  🏥  Doctor gets dashboard. Hospital gets admin panel. Everyone wins.
```

| Layer | Stack |
|-------|-------|
| Frontend | React 19, TypeScript, TailwindCSS 4, TanStack Router |
| Backend | TanStack Start (SSR), Vite 7, Nitro |
| Database | Supabase (PostgreSQL + RLS + Auth + Storage) |
| AI Models | Groq `llama-3.3-70b` + NVIDIA endpoints |
| Monitoring | Sentry, Playwright E2E |
| Infra | Vercel, Cloudflare CDN + WAF |
